◆ Next()

bool DITSEngine::DeviceDIT::Next ( byte nodeIdx = BNONE,
bool InclDel = false )

Advances the iterator to the next table entry.

Note
The iterator remains at its current position if no next entries are found.
Parameters
[in]nodeIdx(default BNONE = no filter) Skips non-deleted entries that don't match nodeIdx.
[in]InclDel(default false = skip deleted). True allows stopping at deleted entries (no node match possible).
Returns
true if the iterator successfully advanced to a matching entry; false if the end of records is reached.
