bool DITSEngine::\+\+Radio\+Pkt\+Max\+Bytes (\begin{DoxyParamCaption}\item[{uint16\+\_\+t}]{max\+Bytes}{}\end{DoxyParamCaption})}



Sets the maximum packet size for the radio interface. 

This function sets the maximum allowable packet size (in bytes) for the radio interface used by the \doxylink{class_d_i_t_s_engine}{DITSEngine}. The value is used to segment outgoing packets into smaller chunks (e.\+g., REQDEVITBL device pools) that fit within the radio\textquotesingle{}s hardware limits. This ensures that the maximum allowed payload size per packet does not exceed the radio\textquotesingle{}s transmission capability. 
\begin{DoxyParams}[1]{Parameters}
\doxymbox{\texttt{in}}  & {\em max\+Bytes} & The maximum number of bytes a single radio packet can carry. \\
\hline
\end{DoxyParams}
\begin{DoxyNote}{Note}
The value is volatile and resets to 58 bytes after every power cycle. The valid range for {\ttfamily max\+Bytes} is 10 to 512 bytes. Any value out of this range will be ignored. The 512-\/byte limit is defined by the protocol, not the radio hardware. 
\end{DoxyNote}
\begin{DoxyReturn}{Returns}
true if the value was set successfully, or false if the value is out of range. 
\end{DoxyReturn}
