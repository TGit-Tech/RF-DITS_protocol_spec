\doxysubsection{Detailed Description}
Central engine managing Node and Device DIT tables, packet transport, and hardware abstraction. 

Responsibilities:\+
\begin{DoxyItemize}
\item Encapsulates Node/\+\+Device metadata (DIT tables) and provides read-\/only access to implementers.
\item Handles memory storage and retrieval of Node/\+\+Device metadata via a pluggable memory backend.
\begin{DoxyItemize}
\item Supports EEPROM, RAM, or other persistent memory via overridable \doxylink{group___o_v_e_r_l_o_a_d_ga2827cdcab4cb3bc50cdfe0f943ab8b1d}{pmem\+\_\+read()}/\+pmem\+\_\+write().
\end{DoxyItemize}
\item Provides Rx/\+\+Tx packet handling for RF or UART transport.
\begin{DoxyItemize}
\item Incoming bytes are processed via Rx\+Byte(), which automatically collects packets and validates them.
\item Outgoing packets can be generated internally when requested by the engine (e.\+g., REQDITINFO, PKT\+\_\+\+VAL).
\end{DoxyItemize}
\item Defines abstract hardware interface functions (virtual methods) for implementers to override:\+
\begin{DoxyItemize}
\item Read\+Pin(), Write\+Pin(), or other device-\/specific control logic.
\end{DoxyItemize}
\end{DoxyItemize}

Behavior Notes:\+
\begin{DoxyItemize}
\item On construction, scans Node Pool and Device Pool to track last-\/used memory blocks.
\item When writing a new Node/\+\+Device:\+
\begin{DoxyItemize}
\item If idx is provided, overwrites that block.
\item If idx==-\/1 (default), finds first deleted block or appends at the end.
\item Updates last-\/used address when writing at the end.
\end{DoxyItemize}
\item Deletion simply marks the first byte of a block as 0x\+FF.
\item Node/\+\+Device structures are exposed as read-\/only nested types (\doxylink{class_d_i_t_s_engine_1_1_node_d_i_t}{Node\+DIT} /\+ \doxylink{class_d_i_t_s_engine_1_1_device_d_i_t}{Device\+DIT}).
\item Event propagation (alarms, device value changes) is outside the scope of this engine.
\end{DoxyItemize}

Access Notes:\+
\begin{DoxyItemize}
\item Implementers interact via:\+
\begin{DoxyItemize}
\item {\ttfamily const Node\+DIT\texorpdfstring{$\ast$}{*} Get\+Node(idx)} or {\ttfamily const Device\+DIT\texorpdfstring{$\ast$}{*} Get\+Device(node\+Idx, dev\+Idx)} for read-\/only access.
\item Virtual hardware functions for physical control.
\item Rx/\+\+Tx functions for communication; engine handles protocol-\/specific packet construction and parsing.
\end{DoxyItemize}
\end{DoxyItemize}

Purpose:\+
\begin{DoxyItemize}
\item Separates protocol logic, memory storage, and hardware control from implementer code.
\item Provides a single, cohesive interface for accessing DIT metadata, handling packets, and controlling hardware. 
\end{DoxyItemize}
