RF-\/\+DITS is an RF-\/\+Lo\+Ra protocol that indexes \textquotesingle{}nodes\textquotesingle{}, each having multiple \textquotesingle{}devices\textquotesingle{} wired to it. The protocol stores in the \textquotesingle{}thisnodes\textquotesingle{} persistent memory the following information:\+
\begin{DoxyItemize}
\item Names of other nodes
\item Device types (including RO/\+\+RW permission, value limits, enumerated-\/set options, and value scaling)
\item RF Addresses of other nodes it plans to communicate with.
\end{DoxyItemize}

Each node stores information about the other nodes it communicates with, which allows the protocol to use index-\/addressing rather than textual addressing for communication.


\begin{DoxyItemize}
\item pmem The persistant memory NDITs and DDITs information is stored-\/in.
\item NDIT \+[N]\+ode \+[D]\+ev \+[I]\+ndex \+[T]\+able; An idx\textquotesingle{}ed list(\+NNode\+Idx) of nodes to communicate with inc. itself.
\item DDIT \+[D]\+evice \+[D]\+ev \+[I]\+ndex \+[T]\+able; An idx\textquotesingle{}ed list(\+Dev\+UID) of Devices belonging to a \textquotesingle{}node\textquotesingle{}(DNode\+Idx).
\end{DoxyItemize}\hypertarget{index_Limits}{}\doxysection{\texorpdfstring{Limits}{Limits}}\label{index_Limits}

\begin{DoxyItemize}
\item A Node\+Idx = 0x\+FF indicates that the table is flagged as deleted.
\item \textquotesingle{}RFAddr\textquotesingle{} is the identifier used in Remote Acces Identity.
\end{DoxyItemize}
\item \textquotesingle{}Dev\+UID\textquotesingle{} -\/ The Remote Acces Identifier for a Device. (Not \textquotesingle{}DDITidx\textquotesingle{}).
\begin{DoxyItemize}
\item \textquotesingle{}DDITidx\textquotesingle{} is the index of a DDIT (device tables) record/\+slot stored in persistant memory.
\item \textquotesingle{}Dev\+UID\textquotesingle{} is stored inside the DDIT record itself.
\item Note:\+ However, \textquotesingle{}Dev\+UID\textquotesingle{} is once-\/derived during Add\+This\+Node\+Device on a continous-\/count of devices on a node.
\item That continous-\/count of added devices on a node is to ensure uniqueness per node RF-\/\+Address.
\end{DoxyItemize}

\begin{DoxyItemize}
\item The memory manager requires (4 Bytes per node + \+\_\+\+Name\+Field\+Bytes).
\item The memory manager requires (3 Bytes per Device + \+\_\+\+Name\+Field\+Bytes).
\item Node-\/\+Tables are allocated separate from the device pool, so the overall memory boundary is determined by what fits.

\item Maximum bytes per packet communication:\+ 512 bytes due to Sec\+Net encoding.
\begin{DoxyItemize}
\item The protocol is designed to perform segmentation when Radio\+Pkt\+Max\+Bytes is set to less than the number of payload bytes required.
\end{DoxyItemize}
\item Number of possible Sec\+Net code combinations:\+ 128 unique (0x00 to 0x7F)
\item Maximum devices per node depends on (\+\_\+\+Name\+Field\+Bytes).
\begin{DoxyItemize}
\item All configuration information needs to fit in the 512 maximum bytes per packet.
\item Use equation. Max Devices a Node = (512 -\/ (4 + Name\+Bytes)) /\+ (3 + Name\+Bytes).
\item So with a \+\_\+\+Name\+Field\+Bytes = 10
\begin{DoxyItemize}
